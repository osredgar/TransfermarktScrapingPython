I love football and also love data, so I'm sharing this tool with all of you.

Bellow what's important to know:

To access the data from competition (check competition list bellow) you must append tm/competition_id/season_year to this URL.

For example, data from Brasileirão Serie A: THIS_URL/tm/8/2022
